# BuildSphere Infra & Engineering Works

A modern, responsive construction and structural engineering web platform built with a high-end architectural aesthetic, dynamic interactive tools, and a robust Express backend.

## 🌟 Key Features

- **Interactive Construction Cost Estimator**: Real-time calculation based on project type, plot footprint, floor structure, and material quality tiers.
- **Customer Live Project Tracker**: Allows clients to track real-time milestone progress (`BSP-2024-01`, `BSP-2024-02`, etc.) from foundation to handover.
- **BuildSphere AI Construction Assistant**: Floating AI assistant offering guidance on construction costs, warranties, and structural inspections.
- **Projects Portfolio & Lightbox Gallery**: Categorized showcase of residential villas, commercial complexes, structural frameworks, and luxury interiors.
- **Secure Management / Staff Portal**: Built-in dashboard for enquiry tracking, status updates, and dynamic estimator rate adjustments.
- **Responsive Mobile First**: Modern drawer navigation and sticky bottom quick call/WhatsApp contact bars.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
# or
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Backend**: Node.js & Express REST API
- **Frontend**: Semantic HTML5, Custom Vanilla CSS Design System, Modular JavaScript
- **Database**: Persistent JSON data storage
- **Design System**: Deep Architectural Slate Navy (`#090f1d`), Engineering Gold/Amber (`#f59e0b`), Glassmorphism, Google Fonts Outfit & Plus Jakarta Sans
